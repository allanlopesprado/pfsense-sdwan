# SD-WAN feature comparison

This matrix compares the package's behavior with documented capabilities of selected products. Product features depend on version, deployment, and licensing. The measured application outcomes come from the [CE benchmark](benchmarks/ce-application-ab.md). They describe the tested policies and topology.

| Capability | pfSense SD-WAN package | Documented examples |
| --- | --- | --- |
| Policy steering | Uses explicitly linked native LAN/VLAN rules, with IPv4 and IPv6 in separate policy groups. It can recommend or apply a path according to gateway SLA and required service checks. Matching uses the native rule's network and transport fields. | FortiGate and PAN-OS can select paths based on the applications they identify. Sophos also supports user and group criteria. [Fortinet](https://docs.fortinet.com/document/fortigate/7.6.2/administration-guide/125874/application-steering-using-sd-wan-rules) · [Palo Alto Networks](https://docs.paloaltonetworks.com/sd-wan/administration/sd-wan-traffic-steering-using-policies/define-your-application-based-traffic-steering-policies) · [Sophos](https://docs.sophos.com/nsg/sophos-firewall/21.5/Help/en-us/webhelp/onlinehelp/AdministratorHelp/Routing/SDWANRoutes/RoutingSDWANRoutesManage/index.html) |
| Application health | Active TCP, DNS, and certificate-verified HTTPS checks. HTTPS can also require an exact readiness token. The same IP can be checked through separately provisioned routing tables. Polling remains synthetic. | FortiGate includes response matching, passive WAN measurements, TWAMP, and voice quality scoring. Cisco measures overlay paths with BFD and application probe classes. [FortiOS settings](https://docs.fortinet.com/document/fortigate/7.6.5/cli-reference/838040159/config-system-sdwan) · [FortiGate passive measurement](https://docs.fortinet.com/document/fortigate/latest/administration-guide/208103/passive-wan-health-measurement) · [Cisco Catalyst](https://www.cisco.com/c/en/us/td/docs/routers/sd-wan/26x-later/policies/policies-configuration-guide/enhanced-application-aware-routing-in-cisco-sd-wan/enhanced-application-aware-routing-in-sdwan.html) |
| Path quality and distribution | Gateway RTT, RTT standard deviation, and loss. Selection uses cost, RTT, or configured connection weights. Available bandwidth, real-session quality, and MOS are outside these metrics. | FortiGate documents bandwidth-based selection and jitter or MOS criteria. Individual features apply to their supported modes. [FortiGate selection](https://docs.fortinet.com/document/fortigate/7.6.5/administration-guide/22371) · [FortiOS metrics](https://docs.fortinet.com/document/fortigate/7.6.5/cli-reference/838040159/config-system-sdwan) |
| Loss recovery and existing sessions | New connections can change egress. Established PF states follow native policy, and connections may reconnect after a public source address change. Forward error correction, duplicate delivery, and aggregation of a single flow are outside the package. | Palo Alto Networks and Cisco document forward error correction and packet duplication for supported scenarios. [Palo Alto Networks](https://docs.paloaltonetworks.com/sd-wan/administration/enable-sd-wan-without-auto-vpn/manage-sd-wan-link-failovers/recover-corrupted-or-lost-data-to-improve-reliability) · [Cisco Catalyst](https://www.cisco.com/c/en/us/td/docs/solutions/CVD/SDWAN/cisco-sdwan-design-guide.html) |
| Tunnel and fleet management | Uses compatible VPN gateways and VTIs provisioned in pfSense. Native pfSense owns IPsec, routing, NAT and HA. The package has no controller for branch enrollment, overlays, or automatic tunnel shortcuts. | Fortinet documents ADVPN shortcuts and managed overlay deployment. Cisco SD-WAN Manager provides fleet configuration and monitoring. [Fortinet ADVPN](https://docs.fortinet.com/document/fortigate/7.6.3/administration-guide/637049/advpn-2-0-edge-discovery-and-path-management) · [Cisco Catalyst](https://www.cisco.com/c/en/us/td/docs/solutions/CVD/SDWAN/cisco-sdwan-design-guide.html) |
