**Services → SD-WAN → Updates** can now upgrade the package from the WebGUI on compatible firewalls.

- **Check GitHub** checks the published version. **Upgrade to …** appears when a newer release exists and the account has the native package installation privilege.
- The updater verifies SHA-256, version, and package identity, runs native `pkg`, and checks the service after installation.
- From 0.4.8 onward, install newer releases from this tab. Use the README installer to reach 0.4.8 from an earlier version.
