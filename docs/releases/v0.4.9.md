The SD-WAN Dashboard widget follows the pfSense Gateways monitoring layout.

- Each row shows the gateway name and IP, RTT and RTTsd in milliseconds, loss as a percentage, and a status cell with color and text.
- The address below the name is the next hop. Dynamic gateways use the address read from the interface. A globe identifies the configured default gateway.
- The policy name appears alongside its preferred gateway. The layout accommodates narrow panels and both light and dark themes.
