Versão de laboratório do pacote SD-WAN para pfSense CE.

- O widget do Dashboard apresenta o membro recomendado, a disponibilidade dos caminhos e o horário da última amostra. Inclui prévias nos temas claro e escuro e em largura reduzida.
- As telas de status e diagnóstico usam os componentes de interface do pfSense e oferecem acesso ao log nativo conforme a permissão do usuário.
- Em **Status → System Logs → System → General**, filtre pelo processo **sdwan** para acompanhar início e parada do serviço, mudanças de caminho e falhas. A severidade configurada no firewall determina quais eventos ficam visíveis.
- **Services → SD-WAN → Updates** permite consultar a versão publicada no GitHub.

Na versão 0.3.0, a migração usa o mesmo comando de instalação. O cliente 0.4.0 passa a consultar a versão diretamente em `main`.

Instale no clone de laboratório por **Diagnostics → Command Prompt** com a linha de download e verificação do README. No CE padrão, o pacote mede e recomenda caminhos. O encaminhamento ativo por regra requer o adaptador de core experimental. O projeto é independente da Netgate.
