Lab release of the SD-WAN package for pfSense CE.

- The Dashboard widget shows the recommended member, path availability, and the last sample time. It includes light, dark, and narrow previews.
- Status and Diagnostics use pfSense UI components and offer access to native logs according to the user's permissions.
- Under **Status → System Logs → System → General**, filter for **sdwan** to see service start and stop events, path changes, and failures. The firewall's severity setting determines which events appear.
- **Services → SD-WAN → Updates** checks the version published on GitHub.

Upgrades from 0.3.0 use the same installation command. Starting with 0.4.0, the client checks the version directly on `main`.

Install on a lab clone from **Diagnostics → Command Prompt** using the README download and verification command. On stock CE, the package measures links and recommends paths. Active per-rule forwarding requires the experimental core adapter. This project is independent of Netgate.
