Status, Diagnostics, Forwarding, and the dashboard widget wait for a fresh sample after a native setting changes on a monitored gateway. The check covers the assigned interface, IP family, monitor target, probe settings, disabled monitoring, and forced-down state. On the experimental core, a filter reload requires a sample that matches the current configuration.

The [configuration impact matrix](https://github.com/allanlopesprado/pfsense-sdwan/blob/main/docs/CONFIGURATIONS.md) records the checks, expected effects, and cases that require a pfSense clone.
