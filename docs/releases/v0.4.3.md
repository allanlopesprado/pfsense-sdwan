SD-WAN WebGUI integration with native pfSense CE 2.9.1 permissions and logs.

- **System Logs** submits the filter through the native form and works for accounts with the exact **System → General** page privilege.
- **Forwarding** and the widget show bindings only to accounts that can view firewall rules and gateway groups.
- Publication waits for WebGUI, FreeBSD, and IKEv2 tests and includes UI screenshots.
- **Build pfSense package** builds and compares two packages. The on-appliance check verifies the service, WebGUI registration, package integrity, and telemetry.

This experimental package is independent of Netgate. Stock installations run in observation mode. Per-rule forwarding requires the lab core adapter.
