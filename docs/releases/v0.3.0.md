Lab release with a dashboard widget, gateway monitoring, SLA policies, and a forwarding preview in the WebGUI. Active selection requires the experimental core integration. On stock CE, the package starts in observation mode. This project is independent of Netgate.

Installation, upgrade, and rollback passed in an isolated package root. The FreeBSD lab verified TCP traffic over two WANs, return-path NAT, CARP VIP transfer, and encrypted traffic through a VTI. Acceptance testing with the CE 2.9.1 image and a physical or virtual FortiGate remains pending.
