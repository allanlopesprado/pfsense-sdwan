SD-WAN WebGUI refresh for pfSense CE 2.9.1.

- **Status** uses the sortable tables, status column, and terminology of **Status → Gateways**.
- **Members**, **Performance SLAs**, and **Policies** follow the **Gateway Groups** list, with action icons, double-click editing, and the **Add** toolbar below the table.
- **Diagnostics**, **Forwarding**, and **Updates** use pfSense form classes. **System Logs** opens the General log filtered for `sdwan`.
- The widget follows the **Gateways** layout, with distinct columns for the recommendation and status.

This experimental package is independent of Netgate. The README includes SHA-256-verified installation.
