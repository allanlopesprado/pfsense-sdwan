Filter reload recovery for experimental SD-WAN forwarding.

- The observer retries when the native service fails to acknowledge a reload request. Tests cover an absent service, timeout, closed connection, negative response, configuration change, and binding removal.
- FreeBSD tests verify IPv6 traffic across both links, including a link-local next hop. A control flow uses the default route while the policy blocks traffic after losing all eligible paths.
- The CARP test tracks LAN and WAN VIP transfer and verifies new TCP transactions using the WAN VIP after NAT.
- Actions checks upgrades and rollback between 0.4.3 and 0.4.4, along with earlier versions.
- In lab mode, the core preparation tool accepts the original CE 2.9.1 file with the documented SHA-256.

The package starts in observation mode on stock pfSense. Validate active forwarding on a clone with two paths and the matching core integration. Queue acknowledgement precedes rule generation and loading by PF.
