Validation with one to three links and safeguards against shared physical dependencies.

- The forwarding preflight follows VLAN, QinQ, LAGG, bridge, and PPP dependencies configured in pfSense. It rejects two members that depend on the same port. Review bindings on composite interfaces after upgrading.
- VTI-bound rules require a specific protected destination. For a broad WAN policy, put explicit exceptions for local, static-route, and VPN networks above the policy.
- Actions exercises loss and recovery with real dpinger processes, IPv4 and IPv6 rule generation, NAT, inbound connection return paths, IPsec, and independent rule regressions. IKEv2 runs with one, two, and three strongSwan tunnels.
- The upgrade and rollback suite includes 0.4.5.

On stock CE, the package runs in observation mode. Active forwarding uses the core integration and requires separate acceptance testing. The impact matrix records combinations that require a pfSense clone and real peers.
