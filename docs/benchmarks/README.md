# SD-WAN forwarding benchmarks

These tests measure what the SD-WAN forwarding adapter changes relative to the native pfSense gateway group. Each report gives the version, topology, fault, source of each measurement and the raw evidence. The released package is SD-WAN 0.4.28. Active forwarding on pfSense CE in these tests uses the matching experimental adapter and explicitly bound LAN rules. Stock CE runs the package in observation mode.

## Reading the measurements

- **Application recovery** is time to a successful reply for a new request on the expected WAN. The FreeBSD comparison also reports the third consecutive success, failures and timeouts, response and TCP-connect latency, the source address seen by the remote service, and outcomes for the separate existing TCP connection.
- **PF convergence** is time to an observed kernel rule for the expected path. The CE interface study captures the tracker, `route-to`, next hop, ICMP gateway RTT and the limits of each observation window. Gateway pings originate on the firewall.
- **Censored** means a requested transition was absent during the observation window. Read the window and sample count with that result. Compare differences only within the same setup and fault. The suite has no bandwidth-capacity comparison.
- **Coverage** includes a published native gateway setup, scoped direct-WAN forwarding, simulated application loss, virtual interface interruption, both-WAN loss, restoration, observer restart, reboot and rollback. Results for actual circuits, combined CE high availability with a licensed FortiGate peer, and other hardware and package combinations depend on their own test runs. See the [evidence by environment](../RESULTS.md) and [configuration impact matrix](../CONFIGURATIONS.md).

The operational sample came from a single CE 2.9.2 appliance running 0.4.28. The default IPv4 gateway group was `WAN_FAILOVER`, using WAN1. The bound LAN rule selected WAN2. WAN1 RTT ranged from 1.858 to 1.866 ms and measured RTT deviation from 0.094 to 0.123 ms. WAN2 RTT ranged from 1.378 to 1.383 ms and deviation from 0.065 to 0.087 ms. Both links reported 0.000% loss in all four observer samples. The 16 polls include repeated readings of the same snapshot and were collected with both links online.
