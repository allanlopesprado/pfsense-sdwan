# Reporting a security issue

Use GitHub's [private vulnerability reporting](https://github.com/allanlopesprado/pfsense-sdwan/security/advisories/new) for security issues. Include the affected pfSense and SD-WAN versions, the operating mode, and the observed impact.

Use [Issues](https://github.com/allanlopesprado/pfsense-sdwan/issues) for general bugs and compatibility reports.
